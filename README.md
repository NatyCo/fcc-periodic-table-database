# Periodic Table Database

This is my solution for the "Periodic Table Database" project, which is part of the **Relational Database Certification** on freeCodeCamp.

## 🛠️ Project Stages
1. **Database Repair:** Fixed columns, data types, added missing elements (Fluorine and Neon), implemented `UNIQUE` and `NOT NULL` constraints, and restructured data using a `types` table in PostgreSQL.
2. **Version Control:** Managed the repository history following *Conventional Commits* rules using Git.
3. **Bash Scripting:** Created `element.sh` to fetch data from the database using an atomic number, symbol, or element name as an argument.

## 🚀 Technologies Used
* **Bash** for the user interaction and data parsing.
* **PostgreSQL** for query optimization and relational database storage.
* **Git** for version control.
